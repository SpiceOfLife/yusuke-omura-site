叩いて録音できるドラムキット「ours-blanc Drum Kit」を公開しました。ブラウザでそのまま遊べて、Mac / Windows のアプリと、DAW 用のプラグイン（VST3 / AU）もあります。すべて無料です。

ブラウザ版：[https\://ours-blanc.app/lab/drumkit/](https://ours-blanc.app/lab/drumkit/)

## できること

* キック、スネア、クラップ、クローズド／オープンハイハット、タム 3 つ、クラッシュ、ライドの 10 種類  
* 録音を押すと再生が始まり、叩いた音が 2 小節のループに重なっていきます  
* 16 分音符で打ち込めるシーケンサー（2 小節）。録音した音もここに並びます  
* クリック、クオンタイズ、BPM の変更

## 叩き方は 4 通り

パソコンのキーボード、タッチ、ゲームパッド、MIDI キーボードのどれでも叩けます。キーボードは A〜; の段がパッドで、Shift を押しながら叩くと強く鳴ります。Space で再生と停止、R で録音です。

MIDI は General MIDI のドラム配置（36 がキック、38 がスネア、42 がクローズドハイハット…）なので、電子ドラムをそのままつないで叩けます（Chrome と Edge）。

## もとは R36S 用だった

このドラムキットは、もともと携帯ゲーム機 R36S 用に作りました。ゲームパッドの配置が「下ボタンでキック、右でスネア」のようになっているのはそのためです。

音を作る部分は C で書いた一つのプログラムで、それを 3 つの場所で動かしています。

| 動く場所 | 中身 |
| :---- | :---- |
| R36S | RetroArch のコア |
| ブラウザ | WebAssembly |
| Mac / Windows・DAW | JUCE で作ったアプリとプラグイン |

同じ C のコードなので、どこで叩いても同じ音がします。小さな機械向けに書いたものをブラウザへ持っていく流れは、Polygon Metronome の [WASM-4 / R36S 版](https://yusuke-omura.pages.dev/blog/20261028-wasm-4) と同じです。

## DAW で使う

プラグイン版は MIDI ノートで鳴らせて、録音とシーケンサーは DAW のテンポと再生位置に合わせて動きます。Mac（macOS 11 以降、Apple Silicon / Intel）はスタンドアローン・VST3・AU、Windows（10 / 11、64 ビット）はスタンドアローン・VST3 です。どちらも約 5MB です。

いまは開発者の署名なしで配布しています。Mac で「開発元を検証できません」と出たら、システム設定の「プライバシーとセキュリティ」で「このまま開く」を押してください。

R36S 版は、ダウンロードした ports フォルダの中身を microSD カードの EASYROMS/ports/ にコピーすると、メニューの Ports に「Drum Kit」が並びます。
