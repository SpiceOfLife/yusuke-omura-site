手元の携帯ゲーム機 R36S が起動しなくなったので、OS を一から入れ直しました。R36S は同じ名前でも中身の違う個体が多く、液晶の種類を間違えると画面が真っ黒のままになります。古いカードから自分の個体を特定し、最新の OS を入れて、ゲームとセーブデータを戻すまでの手順を残しておきます。

## **R36S の仕組み**

R36S は Rockchip RK3326（4 コア）と 1GB の RAM を積んだ縦型の携帯ゲーム機です。OS は本体ではなく、TF1 スロットに挿した microSD カードに入っています。そのため「システムが壊れた」状態のほとんどは、カードを作り直せば直ります。  
カードには、起動用の BOOT、Linux 本体の領域、ゲームを入れる EASYROMS の 3 つの領域があります。パソコンからは BOOT と EASYROMS が見えます。

## **1\. 古いカードを調べて個体を特定する**

まず壊れたカードをパソコンに挿して、BOOT の中を見ました。使われていた画面の設定ファイル（dtb）は rk3326-rg351mp-linux.dtb で、中には「Game Console R35S/R36S」と書かれています。クローン品に特有のファイル名もなく、純正の R36S だとわかりました。  
液晶の種類は、dtb の中にある液晶の初期化データで判定しました。R36S 用の dtb を液晶の種類ごとに集めたリポジトリ（AeolusUX/R36S-DTB）の各パネルと比べたところ、Panel 4 のものと完全に一致しました（初期化データの長さも同じ 773 バイト）。  
同時に、EASYROMS の中の一部のフォルダが読めないことにも気づきました。カードのファイルシステムが傷んでいて、起動しなくなった原因はカードの劣化だと考えられます。このカードは使い回さず、新しいカードに交換することにしました。

## **2\. バックアップ**

新しいカードに戻すため、EASYROMS の中身（約 51GB）と、BOOT の dtb・boot.ini をパソコンにコピーしました。セーブデータ（.srm や .state）は別のフォルダにもまとめておきます。  
劣化したカードは、大量のファイルを続けて読むと一時的に読めなくなることがありました。コピーは途中から再開できる方法（rsync）で何度かに分けて行い、最後にファイルの数とサイズをカードと突き合わせて、全部そろったことを確かめています。読めなかったフォルダも、時間をおくと読めるようになりました。

## **3\. OS を選ぶ**

R36S の定番だった ArkOS（R3XS 版）は 2026 年 3 月に開発が終わり、後継として dArkOSRE-R36 が案内されています。今回は dArkOSRE-R36 の 2026 年 3 月 8 日版を使いました。このイメージには、基板と液晶の組み合わせごとの dtb が入っていて、Panel 4 用（「R36S-V12 2023-08-18 Panel 4」）もあります。  
ダウンロードした .7z を展開すると 8.3GB の .img になります。リリースページの SHA1 は展開後の .img の値なので、.7z ではなく展開したファイルで照合します。

## **4\. 書き込む前に液晶の設定を入れておく**

dArkOSRE では、書き込んだあとに Windows 用の選択ツールで機種を選ぶ手順になっています。中身を読むと、BOOT 直下の dtb を消して、選んだ機種のフォルダの dtb をコピーしているだけでした。Mac では実行できないので、同じことを書き込む前のイメージに直接行いました。

* BOOT の rg351v-uboot.dtb と rk3326-r36s-linux.dtb を削除
* dtb/r36s/R36S-V12 2023-08-18 Panel 4/ の 2 ファイルを BOOT 直下にコピー

念のため、入れた dtb の液晶の初期化データが、古いカードの Panel 4 のものと同じであることも確かめています。

## **5\. 書き込みと初回起動**

書き込みは Raspberry Pi Imager で行いました。デバイスは「No filtering」、OS は「Use custom」で用意した .img、ストレージは新しい microSD カードを選びます。書き込みと照合で 10 分ほどでした。  
カードを TF1 に挿し、充電器を外して電源を入れると、最初の数分は画面が真っ暗でした。初回は空き領域をゲーム用の領域に広げる処理が走るためで、少し待つと無事にメニューが出ました。dArkOSRE の説明書にも「画面が暗くてもインストールが終わるまで待つ」とあります。慌てて電源を切らないことが大事です。

## **6\. ゲームとセーブデータを戻す**

初回起動でできた EASYROMS に、バックアップを戻します。新しいカードは 64GB でしたが、ゲーム用に使えるのは約 51.0GB で、バックアップ（約 51.7GB）は全部は入りませんでした。容量の大きい PSP のフォルダだけを外して戻し、PSP は後で 2 枚目のカード（TF2）に入れることにしました。  
新しい OS に最初から入っているテーマやツール（PortMaster など）は古いもので上書きしないよう、そのフォルダは対象から外しています。戻したあと、ファイルごとにサイズを比べ、セーブデータ 31 件はすべて中身まで一致することを確認しました。

## **電源の切り方**

カードが傷む原因の一つは、書き込み中に電源が切れることです。電源は、ゲームを SELECT \+ START で終えてから、メニューの START →「QUIT」→「SHUTDOWN SYSTEM」で切るようにしています。電源ボタンの長押しは、画面が固まったときだけにします。

## **まとめ**

* R36S の OS は microSD カードに入っているので、壊れてもカードを作り直せば直る
* 液晶の種類は、古いカードの dtb から判定できる
* 付属のカードは劣化しやすいので、信頼できるメーカーのカードに替える
* 初回起動は画面が暗くても待つ

このあと、自作のメトロノームを R36S で動かすために WASM-4 で作り直しました。その話は「WASM-4 でポリリズム・メトロノームを作る」に書いています。
