ポリリズム・メトロノーム「Polygon Metronome」を、携帯ゲーム機 R36S とブラウザで動く WASM-4 版として作り直しました。無料で、ブラウザならインストールなしですぐに試せます。  
![Polygon Metronome WASM-4 / R36S 版][image1]  
WASM-4 版のページ：[https\://metronome.ours-blanc.app/r36s/](https://metronome.ours-blanc.app/r36s/)  
Web 版（すべての機能）：[https\://metronome.ours-blanc.app/](https://metronome.ours-blanc.app/)

## **Polygon Metronome とは**

複数の連符を同時に鳴らせるメトロノームです。N 連符を N 角形で表示し、4 連は四角、3 連は三角、5 連は五角形で回ります。色も N ごとに決まっていて、画面を見るだけでどの連符がどこで鳴っているかがわかります。  
音程は「基音 × N」の倍音列にしています。4 連と 3 連を重ねると 4:3 で完全 4 度、3:2 なら完全 5 度、5:4 なら長 3 度の響きになり、リズムの比と音程の比が一致します。各連符の 1 拍目はアクセントとして強く長く鳴り、図形の頂点も大きく光ります。  
ピアノで左手が 4 つ、右手が 3 つというような重なりを練習するときに、拍の重なりを耳だけでなく図形の動きでも追えるので、どこで揃ってどこでずれるのかがつかみやすくなります。

## **WASM-4 版でできること**

![4連・3連・5連を重ねて再生しているところ][image2]

* 最大 3 つの連符を重ねて再生（1〜12 連）
* BPM を数える基準の連符を切り替え（画面の \* が基準）
* タップテンポ、BPM の ±1 と ±10
* プリセット：2:3、4:3、4:5、4:3:5、2:3:5、4:7、3:4:5
* 基音の切り替え（C3・E3・G3・A3・C4）と、平均律への丸め（ET）
* 設定の自動保存（次に起動したときも同じ状態から始まる）

画面は 160×160 ドット、色は 1 画面 4 色という WASM-4 の決まりの中で、Web 版の見た目をできるだけ残しました。

## **ブラウザで試す**

[WASM-4 版のページ](https://metronome.ours-blanc.app/r36s/)で「ブラウザで起動」を押すと、その場で動きます。画面をクリックしてから、X キーで再生と停止、矢印キーで項目の選択と値の変更です。スマホでは画面の下に十字キーとボタンが出ます。

## **R36S で遊ぶ**

1. R36S の電源を切り、OS が入った microSD カードをパソコンに挿す
2. [WASM-4 版のページ](https://metronome.ours-blanc.app/r36s/)から「R36S 用パッケージ」（r36s-polygon-metronome.zip）をダウンロードして展開し、中の ports フォルダの中身をカードの EASYROMS/ports/ にコピー
3. カードを R36S に戻し、メニューの「Ports」から「Polygon Metronome」を起動

パッケージには WASM-4 のコアも入っているので、WASM-4 のコアが入っていない OS（dArkOSRE など）でもそのまま起動できます。理由と仕組みは別の記事「R36S で WASM-4 のゲームが起動しないときはコアを自分でビルドする」にまとめています。

### **R36S での操作**

| 操作 | ボタン |
| :---- | :---- |
| 再生 / 停止 | A |
| 項目を選ぶ | 十字キー 上下 |
| 値を変える（長押しで連続） | 十字キー 左右 |
| BPM を ±10 | B を押しながら左右 |
| タップテンポ | BPM の行で B |
| テンポの基準にする | 連符の行で B |
| 終了 | SELECT \+ START |

## **Web 版との使い分け**

WASM-4 版は、音が 4 チャンネルしかないため連符は最大 3 つ、音色はファミコンのようなパルス波と三角波になります。拍は 1/60 秒ごとの画面の更新に合わせて鳴るので、1 拍ごとに最大 16.7 ミリ秒の揺れがあります。ただし長く鳴らしてもテンポがずれていくことはありません。  
6 つまでの連符、レイヤーごとの音量、画面ロック中の再生が必要なときは Web 版を、手元のゲーム機でさっと鳴らしたいときやレトロな音で練習したいときは WASM-4 版をどうぞ。

## **作り方の話**

WASM-4 の制約の中でメトロノームをどう組んだか（タイミング、音、4 色での描き分け、テスト）は「WASM-4 でポリリズム・メトロノームを作る」に書きました。ほかのアプリは [ours-blanc.app](https://ours-blanc.app/) にまとめています。
